# 1주차(자료형, 변수 선언, 조건문 등)

**정수 int
실수 float, double
문자 char
논리 값 bool**

**변수 선언 : 컴퓨터에게 변수의 형태와 이름을 알려 주는 것
자료형 변수 이름;
자료형 변수 이름 = 값; // 초기화 (초기 값 설정)
변수 이름은 첫 글자가 숫자가 될 수 없음
자료형과 변수 이름 사이에는 최소 한 개 이상의 공백이 필요**

<u>**변수 명명 규칙
자료형을 알 수 있는 접두어(소문자) + 변수의 용도를 알 수 있는 단어
변수의 용도를 알 수 있는 단어의 각 단어의 첫 글자는 대문자**</u>

**접두어
int i, n**   

**ex) int iData, nData 등**

**float f
double d, db
char c, ch
bool b, is**

**자료형
<u>int	 %d
float	 %f
double	 %lf
char	 %c
bool	 없음-> %d(임시)</u>**

**연산자**

**대입 연산자
= : 왼쪽에 있는 변수에 오른쪽에 있는 값(변수, 상수 등)을 복사
ex) int nData = 10;
수학에서의 = 과 의미가 다름**

**사칙 연산자**

**+ : 왼쪽에 있는 값과 오른쪽에 있는 값을 더함**

**-  : 왼쪽에 있는 값과 오른쪽에 있는 값을 뺌**

***  : 왼쪽에 있는 값과 오른쪽에 있는 값을 곱합
/  : 왼쪽에 있는 값과 오른쪽에 있는 값을 나눔(몫)
% : 왼쪽에 있는 값과 오른쪽에 있는 값을 나눈 나머지 값**

**증감 연산자**

**++ : 변수의 값에 더하기 1을 한다.
ex ) nData++; :
++nData; :**

**-- : 변수의 값에 빼기 1을 한다.
ex ) nData--; :
--nData; :**

**비교 연산자**

**> : 왼쪽에 있는 값이 크면 참(true) 아니면 거짓(false)
< : 왼쪽에 있는 값이 작으면 참(true) 아니면 거짓(false)
>= : 왼쪽에 있는 값이 크거나 같으면 참(true) 아니면 거짓(false)
<= : 왼쪽에 있는 값이 작거나 같으면 참(true) 아니면 거짓(false)
== : 왼쪽 값과 오른쪽 값이 같으면 참(true) 아니면 거짓(false)
!= : 왼쪽 값과 오른쪽 값이 다르면 참(true) 아니면 거짓(false)**

**논리 연산자**

**&&( 그리고, AND) : 둘 다 참일 경우에만 참
ex ) true && true : true
true && false : false
false && true : false
false && false : false** 

**||(또는, or) : 둘 중 하나라도 참이면 참
ex ) true || true : true
true || false : true
false || true : true
false || false : false**

**! : 논리 값을 부정
!true : false
!false : true**

**복합 (대입) 연산자**

**+= 왼쪽에 있는 변수에 오른쪽에 있는 값을 더한 값을 복사
-= 왼쪽에 있는 변수에 오른쪽에 있는 값을 뺀 값을 복사
*= 왼쪽에 있는 변수에 오른쪽에 있는 값을 곱한 값을 복사
/= 왼쪽에 있는 변수에 오른쪽에 있는 값을 나눈 값(몫)을 복사
%= 왼쪽에 있는 변수에 오른쪽에 있는 값을 나눈 나머지 값을 복사**

**() : 연산의 우선 순위 결정**

**조건문(조건을 확인하고 코드 실행 여부를 결정)
if문 switch문**

**if문 : 괄호 뒤에 ;(세미콜론)이 붙지 않음
조건 1이 true(참)이면 중괄호 안에 있는 내용을 실행
if(조건 1)
{}
else if(조건 2)
{}
else if(조건 3)
{}
else
{}**

bool isA = false;
bool isB = false;

if (isA && isB)
{
printf("ㄷ");
}

<u>**이거에 대한 답은?**</u>

**switch 문**

**switch(변수)
{
case 0: ex) (변수 == 0)
괄호 안에 입력된 변수가 값이 0이면 이 부분에 있는 내용을 실행
break;
case 1: ex) (변수 == 1)
괄호 안에 입력된 변수가 값이 1이면 이 부분에 있는 내용을 실행
break;
default:
위에 있는 모든 case에 부합되지 않는 경우 이 부분에 있는 내용을 실행
break;
}**
